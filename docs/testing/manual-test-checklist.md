# 人工测试清单

## 钱包与网络

- [ ] 未安装 MetaMask 时，页面显示明确的钱包安装提示。
- [ ] 未连接钱包时，页面显示「未连接钱包」状态。
- [ ] 连接钱包后，页面显示缩略地址。
- [ ] 当前网络与部署配置不一致时，页面提示切换网络。
- [ ] 切换账户后，页面刷新当前账户的白名单和投票状态。

## 白名单与投票流程

- [ ] 白名单账户显示「当前账户在白名单中」。
- [ ] 非白名单账户不能提交投票。
- [ ] 白名单账户可以选择候选项并提交一次投票。
- [ ] 投票提交后，页面显示交易 Hash。
- [ ] 投票成功后，图表票数刷新。
- [ ] 同一账户第二次投票会被合约拒绝。
- [ ] 截止时间后，前端按钮不可用或合约拒绝交易。

## 合约与脚本

- [ ] `npm run generate:whitelist` 可以生成 `apps/web/public/whitelist.json`。
- [ ] `npm run compile` 可以完成合约编译。
- [ ] `npm test` 显示全部合约测试通过。
- [ ] `npm run test:gas` 输出 Gas 报告。
- [ ] `npm run deploy:local` 可以在本地 Hardhat 网络部署合约。
- [ ] `npm run export:frontend -- --network localhost` 可以生成前端部署配置。
